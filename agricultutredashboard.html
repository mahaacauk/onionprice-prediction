Algorithm Comparison (R² Scores)

Performance across 7 regression models

Insight: Random Forest achieves 95.9% accuracy (R²=0.9590), capturing complex seasonal-weather-geographic interactions. Simple Linear Regression achieves only 52% (R²=0.52), showing the need for ensemble methods.

Hyperparameter Tuning: max_depth Impact

Tree depth is critical; tree count is not

Finding: max_depth=None delivers 18.8% higher R² than max_depth=5. Unrestricted tree growth captures feature interactions.

Hyperparameter Tuning: n_estimators Impact

Diminishing returns after 50 trees

Finding: Adding trees from 10 to 200 yields only 0.45% improvement (R²=0.9547→0.9590). Use n=50 for speed; n=200 for accuracy.
